## Featured Projects

### Managed Identity and Key Vault

Configured an Azure Web App to retrieve secrets from Key Vault using a system-assigned managed identity and least-privilege RBAC, without storing credentials in the application.

### Azure Policy Governance

Applied an Azure Policy that restricted resource deployment to Australia East and verified that non-compliant deployments were denied.

### Key Vault Monitoring

Sent Key Vault audit logs to Log Analytics, queried the events using KQL and designed a scheduled alert rule.
